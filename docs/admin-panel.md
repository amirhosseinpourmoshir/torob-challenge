# پنل اختصاصی اتصال و مدل‌ها

پنل در `http://localhost:5000/panel` است و از آیکون تنظیمات هدر هم باز می‌شود. رابط Django Admin برای این قابلیت استفاده نشده؛ احراز هویت از حساب امن Django و نشست HTTP بهره می‌برد. فقط کاربر فعال با `is_superuser=True` اجازهٔ خواندن و تغییر تنظیمات دارد.

## راه‌اندازی و ورود

تنظیمات `AI_BASE_URL`، `AI_API_KEY`، `AI_MODEL` و `AI_TIMEOUT_SECONDS` در `.env` منبع پیش‌فرض هستند. برای ساخت اولین مدیر، `PANEL_ADMIN_USERNAME` و `PANEL_ADMIN_PASSWORD` را در همان فایل محلی تنظیم کنید؛ رمز حداقل ۱۲ نویسه باشد. سپس:

```powershell
docker compose up --build -d
docker compose exec -T backend python manage.py bootstrap_panel
```

فرمان اگر مدیر فعال وجود داشته باشد، حساب یا رمز او را تغییر نمی‌دهد. تغییر رمز حساب موجود با `docker compose exec backend python manage.py changepassword admin` انجام می‌شود. در نسخهٔ محلی این تسک، حساب اولیه ساخته شده و اطلاعات آن فقط در `.env` محلی نگه داشته شده است. فایل محیطی، رمزها و کلیدها در Git ثبت نمی‌شوند.

## تنظیمات اتصال

- آدرس پایهٔ HTTPS، کلید جایگزین و زمان انتظار ۵ تا ۱۸۰ ثانیه قابل تنظیم‌اند.
- خالی گذاشتن کلید، مقدار فعلی را نگه می‌دارد؛ «استفاده از کلید تنظیمات اولیه» جایگزین ذخیره‌شده را حذف می‌کند. دکمهٔ برگشت به تنظیمات اولیه، تنظیمات اتصال را به `.env` برمی‌گرداند و پروفایل مدل‌ها را حذف نمی‌کند.
- کلید جایگزین با Fernet رمز می‌شود. کلید رمزگذاری از `DJANGO_SECRET_KEY` مشتق می‌شود؛ هنگام انتقال دیتابیس، این secret را حفظ کنید. در صورت تعویض آن، کلید اتصال را دوباره وارد کنید. پاسخ API هیچ نسخهٔ خام، پیشوند یا پسوندی از کلید برنمی‌گرداند.
- کلید فقط در بک‌اند باز می‌شود؛ به bundle، localStorage یا خروجی تست اتصال نمی‌رود. مقدار جدید فقط هنگام ورود دستی کاربر در فرم و ارسال امن همان درخواست حضور دارد و پس از ذخیره از فرم پاک می‌شود.

## پروفایل مدل‌ها

فقط دوازده شناسهٔ اعلام‌شدهٔ کاربر مجازند. دو مدل `text-embedding-3-*` فقط به `/embeddings` و بقیه فقط به `/chat/completions` متصل می‌شوند. هر پروفایل نام دلخواه، مدل، وضعیت روشن/خاموش و پیش‌فرض دارد. هر endpoint فقط یک پیش‌فرض روشن دارد؛ پیش از حذف یا خاموش کردن پیش‌فرض، مدل دیگری باید انتخاب شود. تغییر پیش‌فرض‌ها تراکنشی و با قفل اتصال انجام می‌شود.

در اولین ورود، پروفایل گفتگو از `AI_MODEL` مجاز محیط ساخته می‌شود و امبدینگ `text-embedding-3-small` است. فراخوانی `core.ai_config.resolve_model(endpoint)` تنظیمات مؤثر و مدل پیش‌فرض را برای اتصال بعدی ایجنت برمی‌گرداند؛ این تسک گفتگو را به ایجنت تبدیل نکرده است.

## تست اتصال

تست فقط با کلیک مدیر انجام می‌شود و ممکن است از اعتبار BoxAPI مصرف کند. یک پیام کوتاه با سقف ۱۶ توکن خروجی یا یک ورودی امبدینگ ارسال می‌شود؛ زمان پاسخ و موفقیت برمی‌گردد، نه محتوای سرویس یا کلید. خطاهای اعتبار و مجوز با متن عمومی نمایش داده می‌شوند. redirect دنبال نمی‌شود، آدرس‌های غیرعمومی در زمان تست رد می‌شوند و درخواست تست برای هر مدیر ده ثانیه محدودیت دارد. هیچ endpoint دیگری مثل `/models` یا `/responses` فراخوانی نمی‌شود.

تمام تغییرات CSRF دارند. ورود ناموفق محدود می‌شود و نشست مدیریت هشت ساعت اعتبار دارد. برای انتشار عمومی، HTTPS و cookieهای امن در تنظیمات محیط استقرار فعال شوند.

## مسیرهای API

- `GET /api/panel/session/` و `POST /api/panel/login/`، `POST /api/panel/logout/`
- `GET/PATCH /api/panel/settings/`
- `POST /api/panel/models/`، `PATCH/DELETE /api/panel/models/<uuid>/`
- `POST /api/panel/models/<uuid>/test/`

بررسی‌ها: `docker compose exec -T backend python manage.py test core catalog` و `docker compose exec -T frontend npm run build`.
