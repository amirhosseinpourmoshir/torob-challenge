# پیشنهاد میزبانی اقتصادی در لیارا

[فهرست مستندات](README.md) · [شروع سریع پروژه](../README.md)

برای دموی کم‌ترافیک این پروژه، یک VPS لیارا با Docker Compose معمولاً از خرید جداگانهٔ برنامهٔ وب، worker و دیتابیس ابری ساده‌تر و ارزان‌تر تمام می‌شود. این پیشنهاد ظرفیت است، نه تضمین پاسخ‌گویی به تعداد مشخصی کاربر هم‌زمان.

طبق [تعرفهٔ رسمی لیارا](https://liara.ir/pricing/) در ۳۰ مهر ۱۴۰۵:

| انتخاب | RAM / CPU / دیسک | هزینهٔ پایهٔ ماهانه |
| --- | --- | --- |
| VPS مشتری؛ شروع اقتصادی | ۲ گیگابایت / ۱ هسته / ۲۰ گیگابایت | ۱٬۴۷۵٬۰۰۰ تومان |
| VPS زحل؛ فضای بیشتر برای هم‌زمانی | ۴ گیگابایت / ۲ هسته / ۴۰ گیگابایت | ۲٬۶۵۰٬۰۰۰ تومان |

هزینهٔ IPv4 ماهانه ۲۰۰ هزار تومان و ترافیک دانلود هر گیگابایت ۲۵۰۰ تومان جداست. پایهٔ ساعتی مشتری ۲۰۴۸ تومان و IPv4 ساعتی ۲۷۷ تومان است؛ یک روز روشن بودن تقریباً ۵۵٬۸۰۰ تومان قبل از ترافیک و اعتبار API می‌شود. تعرفهٔ کنسول هنگام خرید را دوباره بررسی کنید. برای چند روز ارائه، از پرداخت سالانه شروع نکنید.

در بررسی محلی، دیتابیس تقریباً یک گیگابایت بود و سرویس‌ها در حالت بیکار حدود ۲۶۰ مگابایت RAM مصرف داشتند؛ این عدد مصرف اوج جستجو، سیستم‌عامل، ورود داده و کاربران هم‌زمان را شامل نمی‌شود. پلن ۲ گیگابایتی حداقل معقول برای دموی محدود است؛ اگر مصرف RAM یا هم‌زمانی بالا رفت، ارتقا به ۴ گیگابایت انجام شود.

روی VPS کوچک، در `.env`:

```dotenv
WEB_CONCURRENCY=1
WEB_THREADS=4
AGENT_TURN_TIMEOUT_SECONDS=90
```

سرویس‌ها با دستورهای `compose.production.yaml` در README اجرا می‌شوند. Nginx، Gunicorn، worker و PostgreSQL روی همان ماشین‌اند؛ Redis، موتور جستجوی خارجی، سرویس واسط چت یا پردازش ابری اضافه لازم نیست. مدل همچنان از BoxAPI می‌آید و سرعت/دسترسی آن روی زمان پاسخ اثر دارد. دریافت نقشه و آدرس معکوس نیز اتصال بیرونی خودشان را دارند؛ صرف خرید هاست، تأخیر این سرویس‌ها را حذف نمی‌کند.

برای انتشار واقعی هنوز دسترسی VPS، دامنه و انتقال امن دیتابیس/محیط لازم است. هیچ رمز یا کلیدی را وارد مخزن نکنید. این صفحه راهنمای انتخاب VPS است؛ مسیر PaaS که با CLI اجرا شده و وضعیت بررسی‌شدهٔ آن در [راهنمای CLI لیارا](liara-cli.md) آمده است.
