نسخهٔ آنلاین برای استفاده از چت، نقشه، ویترین و ذخیره‌ها به حساب ادمین نیاز ندارد. ورود داده روی سرور انجام شده: ۲۲۵٬۹۰۳ محصول، ۳۳۱٬۵۰۶ پیشنهاد فروش و ۶٬۴۷۶ فروشگاه. دادهٔ خام و کلید مدل داخل مخزن توزیع نمی‌شوند. وجود این اطلاعات در سرور به معنی حضور آن‌ها در clone نیست.

## مسیر پیشنهادی ارائهٔ پنج‌دقیقه‌ای

1. تم روشن و تاریک و ثبت یک آدرس در تهران را نشان دهید.
2. نیاز واقعی بنویسید؛ مثلاً «برای موسیقی هدفون انکر تا ۵ میلیون می‌خوام». نتیجه به کاتالوگ موجود وابسته است.
3. به سؤال روشن‌کننده یا بودجه پاسخ دهید؛ مشخصات محصول و مشابه‌های مرتبط را باز کنید.
4. دو محصول را مقایسه کنید و در صورت وجود داده نمودار قیمت را نشان دهید.
5. فروشندگان را روی نقشه بیاورید؛ یک فروشگاه را انتخاب و مبدأ و مقصد، ویترین و فاصله را بررسی کنید.
6. محصول و فروشگاه را ذخیره کنید و از منوی یکپارچهٔ ذخیره‌ها دوباره باز کنید.
7. متن استعلام قیمت و موجودی را آماده کنید؛ توضیح دهید که ارسال خودکار یا تماس واقعی هنوز پیاده نشده است.

نمایشگاه کامپوننت‌ها دادهٔ نمایشی دارد؛ نمایش یک ویجت در آن، اثبات وجود آن داده در کاتالوگ واقعی نیست. برای ضبط ویدئو از مسیر اصلی برنامه استفاده کنید.

## اجرا پس از دریافت سورس

```powershell
git clone https://github.com/amirhosseinpourmoshir/torob-challenge.git
cd torob-challenge
Copy-Item .env.example .env
```

پیش از اجرا، `.env` را مطابق [تنظیمات](configuration.md) تکمیل کنید: رمز دیتابیس، secret مخصوص Django، نام و رمز مدیر و اتصال مدل لازم‌اند. رمز مدیر را خودتان با حداقل ۱۲ نویسه انتخاب کنید؛ هیچ رمز مشترک پیش‌فرضی روی نصب‌ها تحمیل نمی‌شود. کلید سرویس را از حساب خودتان دریافت کنید.

فایل‌های `shops.csv`، `products.csv` و `offers.csv` چالش را در `dataset/` قرار دهید و اجرا کنید:

```powershell
docker compose -f compose.production.yaml up -d --build
docker compose -f compose.production.yaml exec backend python manage.py import_torob --path /dataset
docker compose -f compose.production.yaml exec backend python manage.py audit_catalog
```

برنامه: http://localhost:5000 و پنل: http://localhost:5000/panel . با `PANEL_ADMIN_USERNAME` و `PANEL_ADMIN_PASSWORD` همان فایل محلی وارد شوید. bootstrap فقط اولین مدیر را می‌سازد؛ تغییر `.env` رمز مدیر موجود را تغییر نمی‌دهد. برای تغییر رمز موجود:

```powershell
docker compose -f compose.production.yaml exec backend python manage.py changepassword admin
```

اگر نام مدیر متفاوت است، `admin` را با همان نام جایگزین کنید. به [راهنمای پنل](admin-panel.md) و [عملیات](operations.md) برای بازیابی دسترسی، تست و backup مراجعه کنید.

## دسترسی مدیریت نسخهٔ آنلاین

پنل فعلی فقط برای مدیر کامل است و حالت حساب داور محدود ندارد. نام و رمز مدیر واقعی، کلید BoxAPI، رمز PostgreSQL و توکن لیارا در مخزن عمومی منتشر نمی‌شوند. در صورت نیاز به بررسی پنل آنلاین، مالک پروژه اطلاعات ورود را به داور مشخص از راه خصوصی تحویل می‌دهد. برای بررسی مستقل پنل، نصب محلی و حسابی که خودتان در `.env` ساخته‌اید قابل استفاده است.

## انتشار و نسخه‌بندی

[راهنمای CLI لیارا](liara-cli.md) ورود، انتخاب تیم، تنظیم محیط، PostgreSQL و انتشار را توضیح می‌دهد. پس از آماده‌سازی آن راهنما:

```powershell
.venv/Scripts/python.exe scripts/liara.py check
.venv/Scripts/python.exe scripts/liara.py deploy
```

push سورس به GitHub، دستور deploy نیست. این تحویل مستندات را به‌روز می‌کند و سرویس آنلاین را بازنشر نمی‌کند. برای شناسهٔ دقیق نسخهٔ دریافتی و پیام فارسی کامیت:

```powershell
git log -1 --format=fuller
git rev-parse HEAD
```

[آخرین کامیت main](https://github.com/amirhosseinpourmoshir/torob-challenge/commits/main/) و [تاریخچهٔ تغییرات](../CHANGELOG.md) مرجع‌اند؛ هش یک کامیت نمی‌تواند در محتوای همان کامیت درج شود.

## محدودیت‌های مهم برای ارزیابی

- قیمت ثبت‌شده جای تأیید امروز فروشنده را نمی‌گیرد؛ استعلام فعلی متن و لینک می‌دهد.
- فاصلهٔ داخلی مستقیم است؛ مسیر خیابانی در سرویس بیرونی باز می‌شود.
- دیتاست خام مستقل توزیع می‌شود؛ نصب تازه بدون import یا restore کاتالوگ قبلی را ندارد.
- جستجوی فعلی PostgreSQL و قواعد متن/مدل است؛ جستجوی برداری و تماس خودکار ادعا نمی‌شوند.
- عملکرد به سرویس مدل و ظرفیت پلن وابسته است؛ آزمون فشار با ظرفیت مشخص انجام نشده است.
- فونت‌ها و منابع ثالث تابع شرایط صاحبان خود هستند؛ عمومی‌بودن مخزن مجوز مستقل بازتوزیع آن‌ها محسوب نمی‌شود.
